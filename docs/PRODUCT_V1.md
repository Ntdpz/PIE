# PIE V1 — ขอบเขตที่ยืนยัน

เอกสารนี้เป็นข้อกำหนดปลายทาง ไม่ได้หมายความว่าทำครบแล้ว ดูสถานะจริงใน ROADMAP.md

- Android APK ไม่ต้อง Login; พื้นที่พูดทุกเรื่อง ระบาย บ่น และเก็บชีวิตประจำวัน
- หน้าแรกปุ่มชวนเขียนขนาดใหญ่ เมนูล่าง หน้าแรก / ย้อนวัน / ตั้งค่า
- วันละหนึ่งหน้า ไม่จำกัดข้อความ เขียนต่อได้หลายรอบ Emoji และ # เป็นข้อความธรรมดา
- Auto Save พร้อมสถานะจริง ข้อความอยู่กับวันที่ของหน้าที่เปิดแม้ข้ามเที่ยงคืน
- ปฏิทินย้อนอ่าน เขียนย้อนหลัง แก้ไข และลบได้ ยืนยันก่อนลบ ไม่มีถังขยะ
- เลือกรูป/วิดีโอจากเครื่อง เก็บสำเนาคุณภาพเดิมใต้ข้อความ ไม่มีแชร์ กล้อง หรือตัดต่อในแอป
- ไม่จำกัดจำนวนสื่อ แต่ตรวจพื้นที่ก่อนนำเข้า ลบจาก PIE ไม่ลบต้นฉบับ
- PIN 6 หลักเป็นตัวเลือก ล็อกเมื่อออกจากแอป ซ่อนภาพใน recent apps เปลี่ยน/ปิดด้วย PIN เดิม
- ไม่มีการกู้ PIN; ลืมต้องล้างข้อมูลแล้วเริ่มใหม่
- แจ้งเตือนเลือกเปิดเอง ค่าเริ่มต้นทุกวัน 21:00 ตั้งวัน/หลายเวลาได้ มีปุ่มทดสอบ
- ข้อความแจ้งเตือนกำหนดเองหรือสุ่มจากรายการวันละครั้ง วันเดียวใช้ข้อความเดียว ไม่แสดงเนื้อหาไดอารี่
- เตือนแม้เขียนในวันนั้นแล้ว
- เก็บข้อมูลหลักในเครื่อง ไม่มี analytics upload
- สำรองด้วยตนเองเป็นไฟล์เดียวรวมข้อความ/สื่อ/ตั้งค่า เข้ารหัสด้วยรหัสผ่านแยกจาก PIN ไม่มีการกู้รหัส
- นำเข้าเฉพาะตอนแอปว่าง ตั้ง PIN ใหม่และเปิดแจ้งเตือนใหม่เอง
- จำนวนวันที่เขียน การกลับมาเขียน และเวลาใช้งานเก็บในเครื่อง ไม่รวม Backup
- Google Drive Sync เป็น V2

ต้องยืนยันการออกแบบความปลอดภัยในเครื่องก่อนส่ง V1: PIN เป็น access gate ไม่ใช่การเข้ารหัสโดยตัวมันเอง
